# Task: Draft a landing page outline + copy

You are drafting a landing page. One page, one job.

## Inputs

- Product or feature: {{product_or_feature}}
- Primary audience: {{audience}}
- One action the page must drive: {{primary_action}}
- Channel sending traffic here: {{traffic_source}}
- Length constraint: {{length_constraint_or_default_one_screen_hero_plus_three_sections}}
- Brand-voice doc to honour: {{brand_voice_doc_path}}
- Product KB section to read first: {{product_kb_section}}

## Steps

1. Read the brand-voice doc and the product KB section above. Note
   any facts you will rely on.
2. Write the four-line intake block: Audience, Decision, Action,
   Constraint.
3. Propose two angles, A and B. Each gets a one-line framing and a
   draft hero headline. Recommend one. Say why in one sentence.
4. Outline the page in five blocks: hero, proof, how it works,
   objections, CTA. For each block deliver:
   - Primary copy.
   - Alt copy (a different angle, same job).
   - Any `{{stat}}` or `[UNVERIFIED: ...]` markers where the KB was
     silent.
5. Close with a CTA block: button label, supporting line, and the
   single next step.

## Output format

- Intake block (4 lines).
- Angle A vs Angle B comparison + recommendation.
- Five-block outline with primary and alt copy.
- CTA block.
- Unverified claims section (or "Unverified claims: none.").

## Do not

- Do not write a second CTA. One page, one action.
- Do not name competitors.
- Do not use intensifiers without a concrete noun attached.
