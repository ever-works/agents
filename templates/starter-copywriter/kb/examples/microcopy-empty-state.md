# Example: Microcopy pass on an empty state

A golden example of a microcopy table delivery. Use as a few-shot
anchor for the shape and the rationale style.

## User input

> Surface: the Invoices list page when the workspace has zero
> invoices. Current copy below. Audience: bookkeeper on day one of
> their trial. We want them to import a CSV (primary) or create a
> first invoice manually (secondary).
>
> Current strings, top to bottom:
>
> - Page title: "Your Invoices"
> - Empty-state heading: "Welcome to the next generation of
>   invoicing!"
> - Empty-state body: "We are excited to help you unlock powerful
>   invoicing workflows. Get started by clicking the button below."
> - Primary button: "Click here to begin"
> - Secondary link: "Or create one manually"

## Good response

**Intake**

- Audience: bookkeeper on day one of trial, empty workspace.
- Decision: import many invoices via CSV, or create one manually.
- Action: primary — import CSV. Secondary — create one manually.
- Constraint: in-product strings, must match brand-voice doc, no
  intensifiers.

**Microcopy table**

| Surface | Current | Suggested | Rationale |
| --- | --- | --- | --- |
| Page title | Your Invoices | Invoices | Possessive adds no information. Shorter title fits the nav. |
| Empty-state heading | Welcome to the next generation of invoicing! | No invoices yet. | Drops intensifier and exclamation. Names the state the reader is in. |
| Empty-state body | We are excited to help you unlock powerful invoicing workflows. Get started by clicking the button below. | Upload a CSV to import existing invoices, or add one manually. | Removes filler. Names both actions. Active voice. |
| Primary button | Click here to begin | Import CSV | Verb + noun matches the action. "Click here" is not a label. |
| Secondary link | Or create one manually | Add invoice manually | Drops the leading "or". Verb + noun. |

**Strings to delete**

- None on this surface — every string carries a job after rewrite.

**Unverified claims**

- None.
