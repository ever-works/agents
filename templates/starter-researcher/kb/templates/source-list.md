# Template: Source list

Use when the asker wants the sources, not a synthesis. Common
requests: "give me the top sources on X", "what should I read on Y",
"compile a reading list".

## Skeleton

```
Topic: <one line>

Sources (ranked by relevance):

  [1] <title>
      Publisher: <name>
      Date: <YYYY-MM-DD>
      URL: <link>
      Type: primary | secondary | aggregator
      Takeaway: <one line — what the asker learns from this source>
      Why it ranks here: <one line — what makes this source stronger
        or weaker than others on the list>

  [2] <title>
      ...

Gaps:
  - <topic the asker may expect to see covered but no good source
    exists, or sources are stale>

Notes:
  - <freshness, language, paywall status of items above if relevant>
```

## Rules for ordering

1. Primary sources rank above secondary; secondary above aggregator
   summaries.
2. Within a tier, newer beats older when the field has moved.
3. Within a tier, named authors beat anonymous; well-known publishers
   beat unknown.
4. Diversity matters. A list of ten sources that all repost the same
   wire story is one source ten times. Cut to one.

## Rules for each entry

- Date is mandatory. Undated sources go to the bottom and are flagged
  in `Notes`.
- URL is mandatory and must resolve at the time of writing.
- `Type` is one of `primary` (the original document), `secondary`
  (analysis or commentary citing the primary), `aggregator` (a list
  or summary of others' work).
- `Takeaway` is one line. If the source needs a paragraph to
  summarise, you are using the wrong template — use a Research brief
  instead.
- `Why it ranks here` is one line and explains the position
  honestly. "Author is the original researcher" is a strong reason;
  "first result on the search engine" is not.

## What this template is not

Not a citation block for a brief — that's the Sources section in the
Research brief template. This template is the deliverable itself.
