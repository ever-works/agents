# Task: Turn a keyword cluster into a content brief

Produce a brief a writer can execute and that has a real shot at
ranking — grounded in search intent, not keyword density.

## Do

1. Confirm the target keyword cluster and classify the dominant search
   intent (informational, commercial, transactional).
2. Check what already ranks for the cluster and what the tenant already
   has (avoid cannibalising an existing page).
3. Decide the page type that matches the intent.
4. Draft the brief: working title/H1, outline (H2/H3), the questions to
   answer, internal links to and from the page, and the primary +
   secondary keywords used naturally.

## Deliver

A content brief with: keyword cluster + intent, title/H1, outline,
internal links, and the success metric (e.g. rank for cluster,
organic sessions to the page). White-hat only — no stuffing, no spun
content, no fabricated search volumes.
