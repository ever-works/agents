# Playbook: Design a compounding growth loop

Use this when the Task is "how do we grow?", "design a growth loop", or
"reduce dependence on paid". A loop beats a funnel because product
usage feeds the next user instead of the loop stopping when spend does.

## Step 1 — Identify the output

What does the product already produce that could reach a new user?
Shared artifacts, invitations, public content, or external touchpoints
(emails, embeds) are all candidate outputs. Pick the one closest to
core usage.

## Step 2 — Pick the loop type

Classify it: viral/social (invitation, creation, collaboration),
content/SEO (user-generated pages that rank), network-effect (value
rises with users), or paid-reinvestment (LTV funds acquisition). Name
it — the type dictates the metric.

## Step 3 — Map the loop with metrics

```
[Start] → [Action] → [Output] → [New-user touchpoint] → [New user] → [Start]
```

Put a metric on every arrow. For viral loops, the headline metric is
the viral coefficient K (new users generated per existing user):
K > 1 compounds, K < 1 decays. For content loops it's pages published ×
ranking rate × click-through.

## Step 4 — Find the constraint

The weakest step is where to invest. Low K → improve the invite/share
mechanic. Low output conversion → fix the landing/first experience.
Low activation → fix onboarding. Only one constraint at a time.

## Step 5 — Propose experiments

Deliver the top 2-3 experiments that attack the constraint, each with a
hypothesis, the metric it moves, and a decision rule (ship / iterate /
kill). Model the loop economics only when the loop is paid-reinvestment
(needs LTV/CAC > ~3x, payback < ~12 months).

## Output

Loop type, the step diagram with metrics, the named constraint, and the
prioritised experiments. No vanity metrics.
