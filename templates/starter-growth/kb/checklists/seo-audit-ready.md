# Checklist: SEO audit ready to hand over

Run this before declaring a technical + on-page SEO audit complete.

## Technical

- [ ] Crawl run; crawl errors, broken links, and redirect chains listed
- [ ] Duplicate / thin / orphan pages identified
- [ ] Core Web Vitals measured (LCP, INP, CLS) with the URLs that fail
- [ ] Indexation checked (robots, canonical, sitemap coverage)
- [ ] Structured data validated where it applies

## On-page

- [ ] Title + meta description quality checked on priority pages
- [ ] Heading structure (one H1, logical order) verified
- [ ] Internal linking gaps to priority pages noted
- [ ] Image alt text and file weight spot-checked

## Content

- [ ] Keyword clusters mapped to pages by search intent
- [ ] Content gaps vs. competitors identified (not fabricated)
- [ ] Cannibalisation (two pages targeting one intent) flagged

## Delivery

- [ ] Findings grouped Technical / On-page / Content with a severity each
- [ ] Every finding has affected URLs and a concrete fix
- [ ] A monitoring plan is attached: metric, baseline, target
- [ ] No black-hat recommendation anywhere in the report
- [ ] No fabricated search volume or metric — unknowns marked as unknown
