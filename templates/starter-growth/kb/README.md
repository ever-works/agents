# Growth KB

Seeds the Growth / SEO Strategist at create time. Small on purpose —
the agent needs reflexes for the two things it does constantly: audit
search health and design loops that compound.

## Contents

- `playbooks/` — the loop-design procedure the agent runs when asked
  "how do we grow?".
- `checklists/` — the pass/fail list the agent runs before calling an
  SEO audit complete.

## Citation policy

`mix`. Ground strategy in the tenant's own analytics and Search Console
first; external SEO tools (rank trackers, crawlers) and search-engine
guidelines are legitimate sources. Never cite a fabricated search
volume — if a tool didn't produce the number, say it's unknown.

## What this KB intentionally does not contain

- Vendor-specific tool tutorials — the agent adapts to whatever
  analytics/Search Console/crawler the tenant has wired up.
- A fixed keyword list — keywords come from live research per Task.
- Growth targets — those are set with the human, per experiment.
