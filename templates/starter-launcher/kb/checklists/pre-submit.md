# Checklist — Before each submission

Run per platform, every time. Any failing item stops this platform.

- [ ] The tracker has no row for this product and platform with status
      `submitted`, `pending` or `live`.
- [ ] The platform's status in the database is not `down`, or it was
      re-checked today and is up.
- [ ] The product fits the platform's niche and requirements (row
      `best_for` and `requirements`).
- [ ] Copy comes from the approved kit; name, URL and pricing match it
      exactly.
- [ ] The link carries `utm_source=<platform id>`.
- [ ] Every required field has a value; nothing is a placeholder.
- [ ] Assets meet the platform's sizes.
- [ ] No step ahead needs a password, payment, CAPTCHA, terms
      acceptance or identity check from the agent. If one does, the
      step goes to a person on a hand-off card.
- [ ] Any cost is approved by the owner for this platform, in writing.
- [ ] Any reciprocal badge or backlink requirement is recorded for the
      owner to decide.
- [ ] The tracker row is created or updated before moving on.
