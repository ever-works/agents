# Launch platform database — columns

`launch-platforms.csv` is the source of truth. One row per platform.
Edit it in any spreadsheet tool (keep UTF-8 and comma separators),
then regenerate the Markdown view:

```bash
node scripts/render-launch-platforms.js \
  templates/starter-launcher/kb/data/launch-platforms.csv \
  templates/starter-launcher/kb/directories
```

## Columns

| Column          | Meaning                                                                             | Values                                                                                                                                                                                                                                                                                                                                                   |
| --------------- | ----------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`            | Stable kebab-case key. Used as `utm_source` and in trackers. Never reuse or rename. | `product-hunt`, `alternativeto`, ...                                                                                                                                                                                                                                                                                                                     |
| `name`          | Display name.                                                                       | text                                                                                                                                                                                                                                                                                                                                                     |
| `category`      | Where it sits in the launch plan.                                                   | `launch-platform`, `startup-directory`, `company-profile`, `review-site`, `software-directory`, `community`, `dev-community`, `package-registry`, `open-source-directory`, `self-hosting-catalog`, `app-marketplace`, `app-store`, `ai-directory`, `agent-directory`, `newsletter`, `social`                                                             |
| `url`           | Home page.                                                                          | URL                                                                                                                                                                                                                                                                                                                                                      |
| `submit_url`    | Known submission page, when stable. Empty means find it on the site.                | URL or empty                                                                                                                                                                                                                                                                                                                                             |
| `submit_method` | How a listing is created.                                                           | `launch-event` (dated launch), `form`, `account-form`, `vendor-portal`, `profile`, `community-post`, `article`, `editorial-pitch`, `registry-publish`, `developer-program`, `github-pr`, `none` (not submittable; traction-based)                                                                                                                        |
| `automation`    | Who can do it.                                                                      | `auto` (CLI, API or pull request with provisioned credentials), `assisted` (agent prepares and fills; a person signs in, handles CAPTCHA, terms, payment and the final submit), `human` (a person posts in their own voice; the agent drafts)                                                                                                            |
| `cost`          | Price model at the last check. Prices change; check before acting.                  | `free`, `freemium` (free listing, paid upgrades), `paid`, `fee` (developer account fee), `revenue-share`                                                                                                                                                                                                                                                 |
| `link_type`     | Link attribute as reported, not verified. Check the live listing.                   | `dofollow`, `nofollow`, `unknown`                                                                                                                                                                                                                                                                                                                        |
| `traffic`       | Relative audience size.                                                             | `very-high`, `high`, `medium`, `low`                                                                                                                                                                                                                                                                                                                     |
| `difficulty`    | Effort and acceptance bar.                                                          | `easy`, `medium`, `hard`                                                                                                                                                                                                                                                                                                                                 |
| `best_for`      | Fit tags, `;`-separated. Match against the product's tags.                          | `saas`, `b2b`, `b2c`, `ai`, `agents`, `mcp`, `dev-tools`, `api`, `cli`, `oss`, `self-hosted`, `infra`, `indie`, `startups`, `apps`, `desktop`, `mobile`, `browser-extension`, `web`, `web-tools`, `frontend`, `no-code`, `design`, `productivity`, `marketing`, `crm`, `ecommerce`, `wordpress`, `enterprise`, `agency`, `community`, `technical`, `any` |
| `timing`        | Default wave in the launch sequence.                                                | `pre-launch`, `launch-day`, `launch-week`, `week-2-4`, `ongoing`, `when-eligible`                                                                                                                                                                                                                                                                        |
| `requirements`  | What the product or the owner needs before submitting.                              | text                                                                                                                                                                                                                                                                                                                                                     |
| `how_to`        | The practical advice for this platform.                                             | text                                                                                                                                                                                                                                                                                                                                                     |
| `status`        | Result of the last liveness check.                                                  | `up`, `up (blocks automated clients)` (site works, needs a real browser session), `down (...)` (skip and re-check)                                                                                                                                                                                                                                       |
| `last_checked`  | Date of the last check.                                                             | ISO date                                                                                                                                                                                                                                                                                                                                                 |

## Rules for editing

- Add a platform only after opening it and finding a way to submit.
- Mark a platform `down` rather than deleting it; delete only after two
  failed checks a month apart.
- Keep `how_to` practical and short: what to do, what to avoid.
- Never add a platform whose model is buying votes, reviews, stars or
  followers.
