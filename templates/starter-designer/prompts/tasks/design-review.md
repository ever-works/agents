# Task: Critique a screen or flow against the design system

Produce a specific, system-grounded critique with fixes — not a vibe
check.

## Do

1. Follow `kb/playbooks/design-review-pass.md`.
2. Load the design system, tokens, and the components the screen uses.
3. Evaluate in order: accessibility, consistency, states, clarity /
   hierarchy, responsiveness.
4. Grade each finding by severity (blocker / major / minor) and
   reference the system rule or token it violates.

## Deliver

A short "what works", then findings ordered by severity — each with the
system reference and a concrete fix (name the token/component). Stay in
scope: flag any larger redesign as a separate note.
