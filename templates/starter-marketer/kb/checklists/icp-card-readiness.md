# Checklist — ICP card readiness

Run this checklist before saving an ICP card to the KB. Every
item must pass. A failing item means the card is not ready to
ship and the agent must either fix it or ask the owner.

## Identity

- [ ] The segment has a name that describes a JTBD, not an
      industry. "B2B SaaS" fails. "Founders prepping for
      fundraise" passes.
- [ ] The card describes ONE segment. If it tries to describe
      two, it fails — split and run the task again.

## Evidence

- [ ] Every claim on the card cites a source: an interview
      quote, a ticket, a search-volume number, a third-party
      review, or a KB document.
- [ ] At least one direct customer quote appears verbatim on the
      card. No paraphrase.
- [ ] No metric on the card is invented. If the agent had to
      guess, the field reads "unknown — owner to provide".

## Specificity

- [ ] The watering holes section names actual places — specific
      subreddits, newsletters, conferences, slack communities.
      "Social media" fails. "r/SaaS, Lenny's Newsletter,
      SaaStr Annual" passes.
- [ ] The trigger event is concrete. "When they're growing"
      fails. "When they raise a seed round" passes.

## Disqualifiers

- [ ] The card names at least two buyer profiles that LOOK like
      this segment but are NOT. If the agent cannot name any,
      the segment is too broad and the card fails.

## Rethink trigger

- [ ] The card ends with the assumption that, if proven wrong,
      forces a rewrite. Example: "Assumes founders make this
      decision alone; if board involvement is common, segment
      and message both change."

## Save

- [ ] File is saved to `kb/segments/<slug>.md`.
- [ ] The segment list index is updated.
