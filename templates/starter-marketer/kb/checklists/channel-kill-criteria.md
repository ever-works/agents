# Checklist — Channel plan kill-criteria check

Run this checklist before a channel plan goes to the owner. Every
channel in the plan must pass every item. A failing item blocks
the plan.

## Per channel

- [ ] The channel targets one named segment from the segment
      list. Cross-segment channels fail unless the owner has
      explicitly merged the segments for this test.
- [ ] The "why this segment" field names the watering hole or
      intent signal that ties channel to ICP. Generic answers
      ("LinkedIn works for B2B") fail.
- [ ] The leading metric is a metric you can read inside the
      test window. Revenue is not a leading metric for a
      two-week test — it lags. Email signups, demo bookings,
      content engagement can be leading metrics.
- [ ] The target value for the leading metric is set, and the
      card explains how the target was set (benchmark, prior
      campaign, owner instruction). "Some" is not a target.
- [ ] The smallest test is genuinely small — the cheapest
      version that produces a directional answer. A three-month
      content engine is not a test.
- [ ] The kill criterion is a specific threshold with a date.
      "Cut if signups are below 30 by day 14" passes. "Cut if
      it's not working" fails.

## Per plan

- [ ] At most three channels are proposed for the test window.
      More than three is noise.
- [ ] Channels are ranked by compounding potential. If a paid
      channel is ranked above an asset-building channel, the
      plan explains why (usually a hard timing window).
- [ ] No channel requires paid spend without explicit owner
      approval. If paid is recommended, the plan flags it
      clearly.
- [ ] The plan names the next review date. Channels are not
      "set and forget".

## Rethink trigger

- [ ] The plan ends with the assumption it rests on. Example:
      "Assumes the trigger event is fundraising; if buyers
      actually start looking after a board meeting, channel mix
      shifts toward LinkedIn from search."
